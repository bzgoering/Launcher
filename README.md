# Launcher

A personal quick launcher for Windows. Press a hotkey to open launchers and apps without tabbing out of a game or switching windows.

## Tech
- AutoHotkey v2

## How to run
1. Install [AutoHotkey v2](https://www.autohotkey.com/).
2. Double-click `Launch.ahk` (it runs in the system tray).

## Controls
| Key | Action |
|---|---|
| `Home` | Opens the launcher at your mouse position |
| `PgUp` | Turns off the auto clicker |

## Features
- **Open Application**: pick EA, Epic Games, Steam, Minecraft, Battle.net, Ubisoft Connect or Spotify, then press **Enter**
- **Auto Clicker**: tick the checkbox before pressing **Enter**
- **Open Start Up Apps**: opens NZXT CAM, DevilZone and Armoury Crate in one click
- **Google Search**: work in progress
